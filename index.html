Portfolio Volatility Risk Scanner

Built an end-to-end market-risk analytics project that combines Python machine learning with an interactive Power BI dashboard to identify securities with elevated future-volatility risk.

The project scores 204,135 security-date observations covering 502 securities, compares Logistic Regression and XGBoost, and converts predicted probabilities into user-controlled risk alerts.

Result: The selected Logistic Regression model achieved 88.6% recall, a 55.2% F1 score, and a 68.7% ROC-AUC on the final test period. The dashboard exposes the trade-off between detecting volatility events and managing false-positive alerts.

Python Google Colab Pandas Scikit-learn XGBoost Power BI Power Query DAX

Key Findings

  • The selected model detected 88.6% of final-test volatility events.
  • VIX was the leading model driver, with 22.6% relative importance.
  • The 40.1% precision and 75.6% alert rate reveal a material alert-fatigue risk.
  • The adjustable threshold lets users explore the precision-recall trade-off.

Online Shopper Purchase Prediction Dashboard

Developed an end-to-end predictive analytics project combining Python machine learning with Power BI to predict whether an online-shopping session will result in a purchase.

The project analyzed 12,330 website sessions and compared Logistic Regression, Decision Tree, and Random Forest models. Results from 2,441 test sessions were exported into an interactive Power BI dashboard.

Result: Random Forest achieved the strongest ROC-AUC score at 78.2%. The dashboard communicates conversion performance, prediction outcomes, monthly trends, visitor behavior, and the strongest purchase drivers.

Python Google Colab Pandas Scikit-learn Random Forest Power BI Power Query DAX

Key Findings

  • Random Forest achieved the strongest ROC-AUC at 78.2%.
  • November recorded the highest conversion rate at 25.8%.
  • Exit rate was the strongest purchase driver at 17.8%.
  • Product-related page duration was the second-largest driver at 14.2%.
  • New visitors converted at a higher rate than returning visitors.
