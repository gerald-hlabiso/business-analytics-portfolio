# Project Images

High-resolution visualizations for the Cost-Sensitive Heart Disease Screening Decision Support project.

## Visuals

- `held-out-test-performance.png` — executive summary of final model performance
- `test-confusion-matrix.png` — held-out test classification outcomes
- `roc-pr-curves.png` — ROC and precision-recall performance
- `threshold-comparison.png` — default and cost-sensitive threshold comparison

These visuals are based on an educational machine-learning demonstration and must not be interpreted as clinical diagnostic results.
